# 实时工资可视化应用 PRD

## 1. 产品定位

一个轻量级、偏趣味的实时工资可视化 Web 应用。用户输入月薪和每日工作时长后，页面展示每秒、每分钟、每小时收入。点击“开始打工”后，实时计算已工作时长和当前已赚金额，并根据金额解锁预设成就。

## 2. 技术栈

- React
- Vite
- TypeScript
- CSS Modules / 普通 CSS 均可
- 无后端
- 无登录
- 可静态部署

## 3. 核心规则

### 3.1 按自然月计算

系统按当前自然月天数计算日薪。

```ts
当前自然月天数 = 当前月份总天数，例如 28 / 29 / 30 / 31

日薪 = 月薪 / 当前自然月天数
时薪 = 日薪 / 每日工作时长
分钟收入 = 时薪 / 60
秒收入 = 时薪 / 3600
```

示例：

```text
月薪：10000 元
当前月份：31 天
每日工作时长：8 小时

日薪：322.58 元
时薪：40.32 元
每分钟：0.67 元
每秒：0.0112 元
```

## 4. 页面功能

### 4.1 用户输入

输入项：

- 月薪，单位元
- 每日工作时长，单位小时

规则：

- 月薪必须大于 0
- 每日工作时长必须大于 0 且不超过 24
- 输入非法时，“开始打工”按钮不可点击
- 保存用户输入到 `localStorage`
- 不保存当天已工作进度

### 4.2 收入速率展示

实时展示：

- 每秒收入
- 每分钟收入
- 每小时收入
- 今日日薪

金额展示规则：

- 日薪、时薪、分钟收入保留 2 位小数
- 每秒收入保留 4 位小数

### 4.3 开始打工

点击“开始打工”后：

- 状态进入 `running`
- 记录开始时间
- 实时更新已工作时长
- 实时更新当前已赚金额
- 输入项进入禁用状态
- 按钮切换为“收工休息”

计算方式必须基于真实时间差，而不是简单累加定时器。

```ts
已工作秒数 = 历史累计秒数 + 当前时间 - 本次开始时间
当前已赚金额 = 已工作秒数 * 秒收入
```

### 4.4 收工休息

点击“收工休息”后：

- 停止计时
- 保留当前已工作时长
- 保留当前已赚金额
- 状态进入 `paused`
- 按钮切换为“继续打工”

### 4.5 自动完成

当已工作时长达到每日工作时长时：

- 自动停止计时
- 已工作时长固定为每日工作时长
- 当前已赚金额固定为日薪
- 状态进入 `finished`
- 按钮显示“今日已完成”

### 4.6 重置今日进度

提供“重置今日进度”按钮。

点击后：

- 已工作时长清零
- 当前已赚金额清零
- 成就全部恢复未解锁
- 状态回到 `idle`
- 输入项恢复可编辑

## 5. 成就系统

成就不可自定义，使用系统预设。

解锁规则：

```ts
当前已赚金额 >= 成就门槛金额
```

默认成就列表：

| 门槛 | 成就名 |
|---:|---|
| 5 元 | 公交车票到账 |
| 10 元 | 早餐钱到账 |
| 20 元 | 解锁一杯奶茶 |
| 35 元 | 午饭基金启动 |
| 50 元 | 电影票进度达成 |
| 100 元 | 小购物自由 |
| 200 元 | 大餐基金到账 |
| 日薪 25% | 摸到四分之一 |
| 日薪 50% | 半日打工人 |
| 日薪 75% | 快要收工了 |
| 日薪 100% | 今日工资到账 |

若固定金额超过当日可赚日薪，则仍展示，但保持未解锁状态。

## 6. 状态设计

```ts
type WorkStatus = 'idle' | 'running' | 'paused' | 'finished';
```

建议定义核心类型：

```ts
interface SalaryInput {
  monthlySalary: number;
  dailyWorkHours: number;
}

interface IncomeStats {
  daysInCurrentMonth: number;
  dailyIncome: number;
  hourlyIncome: number;
  minuteIncome: number;
  secondIncome: number;
}

type AchievementType = 'fixed' | 'ratio';

interface Achievement {
  id: string;
  name: string;
  threshold: number;
  type: AchievementType;
}
```

状态流转：

```text
idle -> running
running -> paused
paused -> running
running -> finished
paused -> idle，重置
finished -> idle，重置
```

按钮文案：

```text
idle: 开始打工
running: 收工休息
paused: 继续打工
finished: 今日已完成
```

## 7. UI 风格

整体偏趣味、轻松，但不要做成复杂游戏。

建议布局：

- 顶部突出展示“当前已赚金额”
- 中部展示已工作时长、今日进度条
- 下方展示每秒、每分钟、每小时收入
- 成就列表用轻量卡片展示
- 已解锁成就高亮，未解锁置灰

主展示示例：

```text
当前已赚
¥ 48.26

已工作 01:11:49
今日进度 14.9%
```

## 9. 验收标准

1. 输入月薪和每日工作时长后，能正确计算自然月日薪。
2. 能正确展示每秒、每分钟、每小时收入。
3. 点击“开始打工”后，时长和金额实时增长。
4. 点击“收工休息”后，时长和金额停止增长。
5. 点击“继续打工”后，可继续累计。
6. 达到每日工作时长后，自动停止并显示“今日已完成”。
7. 当前已赚金额达到门槛后，对应成就自动解锁。
8. 点击“重置今日进度”后，金额、时长、成就状态全部清零。
9. 刷新页面后，只保留月薪和每日工作时长，不恢复打工进度。
10. 移动端和桌面端布局正常，无明显遮挡或错位。
